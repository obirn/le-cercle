# lecercle

Ceci est le repository pour les scripts utilisés dans le cadre technique de la société Le Cercle des Parfumeurs Créateurs, géré par mon frère et moi.

Il est principalement constitué de scripts permettant de 
- manipuler des csvs et des excels afin d'extraire des données clients,
- envoyer des mailings, en utilisant soit l'api outlook de windows, soit des librairies IMAP et SMTP
